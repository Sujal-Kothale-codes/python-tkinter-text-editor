# Python Tkinter Text Editor

A simple desktop text editor built using Python and Tkinter. This project provides a basic graphical interface for creating, opening, editing, and saving text files.

## Features

- **New File:** Clear the text area to start a new document.
- **Open File:** Open and read existing `.txt` files.
- **Save File:** Save your text content to a file.
- **Exit:** Close the application using the File menu.
- **Simple GUI:** A clean, user-friendly text editing interface.

## Technologies Used

- **Python** — Main programming language.
- **Tkinter** — Python library for creating the graphical user interface.
- **File Handling** — Reading and writing text files.
- **File Dialogs** — Selecting files to open and save.

## Requirements

- Python 3.x
- Tkinter (usually included with standard Python installations)

   ```bash

   ```

3. Run the Python file:

   ```bash
   python python.py
   ```

## How to Use

1. Run the application.
2. Select **File → NEW** to start a new document.
3. Select **File → OPEN** to open an existing text file.
4. Type or edit your text in the editor.
5. Select **File → SAVE** to save your document.
6. Select **File → EXIT** to close the application.
